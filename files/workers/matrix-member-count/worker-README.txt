The "matrix-member-count" worker was written by the Asveora organization (https://github.com/Asveora) and is meant to be deployed with Cloudflare's dashboard. All instructions written inside of worker.js have been written with Cloudflare in mind. If there is another service you want to use, make sure that you understand how API requests work and how workers are structured with javascript. Most of the detailed instructions can easily be transferred into working with another service that offers KV storage and similar features to the ones that Cloudflare provides.
