ID Index
This is an id index that can be implemented as a front-facing searchable database. Simply add another list item to add another searchable entry. Media such as images that do not exist as text strings must be assigned a text string via a hidden name which the search function can look for. ID tags are recommended for each list item as well if you want to be able to link users to a specific entry within the list.
